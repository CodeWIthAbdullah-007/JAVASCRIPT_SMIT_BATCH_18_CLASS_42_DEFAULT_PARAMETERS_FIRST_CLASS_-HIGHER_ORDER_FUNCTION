# JavaScript Default Parameters & Higher-Order Functions 🎯

This project explores **default parameters** and **higher-order functions** in JavaScript.

## Features ✨
- Learn how to assign default values to function parameters.
- Understand higher-order functions: passing functions as arguments and returning functions.
- Improve code reusability and readability.
- Practical examples for real-world scenarios.

## Usage 🚀
1. Clone the repository.
2. Open `index.js` to see examples.
3. Run code using a browser console or Node.js.

- JavaScript functions
- Default parameters
- Higher-order functions
- Functional programming concepts
